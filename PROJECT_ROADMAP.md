# ⚾ Richmond Barons GameDay
*A baseball soundboard and lineup management app for Richmond Barons.*

---

# Vision

The goal of this project is to create the easiest, fastest and most polished baseball soundboard possible.

It should require **zero explanation** to a volunteer using it for the first time.

The app should feel like a professional stadium control panel rather than a generic music player.

Everything should prioritise:

- ⚡ Speed
- 📱 Mobile usability
- ⚾ Baseball workflow
- ❤️ Richmond Barons branding
- 🎵 One-tap operation

Whenever there is a choice between adding complexity or keeping things simple, simplicity wins.

---

# Core Modes

## ⚡ Quick Board

This is the primary match-day interface.

Features:

- All player buttons visible
- Mystery walk-up buttons
- Game effects
- One-tap playback
- Fade Out
- Stop
- Progress bar
- Volume slider

No setup required.

This mode should remain as simple as possible.

---

## ⚾ Lineup Mode

Designed for whoever is running music during the game.

Features:

- Fixed 9-player batting order
- Search players
- Assign players to batting positions
- Assign spare songs if needed
- Easy substitutions
- Move players up/down
- Save lineup
- Load lineup
- Next Batter button
- Now Batting panel
- Next Up panel

Changing the lineup should NEVER interrupt music already playing.
